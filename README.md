## 📌 نظرة عامة

يقدم هذا المستند مقدمة مشتركة لاثنين من أطر العمل المهمة من خلال تنفيذ تطبيق **عميل/خادم**:

* **AngularJS 1.x** للجانب الخاص بالعميل (الواجهة الأمامية)
* **Spring 4** للجانب الخاص بالخادم (الواجهة الخلفية)

للتبسيط، سيتم استخدام مصطلحي **Angular** و **Spring** في بقية هذا المستند.

الهدف هو تقديم توضيح عملي للتفاعلات بين عميل الويب وخادم Java باستخدام تقنيات مستخدمة على نطاق واسع في تطوير تطبيقات الويب الحديثة.

---

## 🎯 الأهداف

* فهم بنية العميل/الخادم
* تنفيذ AngularJS 1.x لتطوير الواجهة الأمامية (frontend)
* استخدام Spring 4 لعرض خدمات الخلفية (backend)
* توضيح التبادلات HTTP بين العميل والخادم
* إدارة قاعدة بيانات عبر JPA

---

## ⚙️ المتطلبات المسبقة

يتطلب فهم هذا المستند المعرفة التالية:

* مستوى متوسط في **Java EE**
* إتقان **JPA (Java Persistence API)**
* معرفة بإصدار سابق من **Spring**
* استخدام **Maven** لإدارة المشاريع
* فهم الاتصال **HTTP**
* مفاهيم أساسية حول:
  * **HTML**
  * **JavaScript**

يتم تقديم مفاهيم إضافية تدريجيًا خلال دراسة الحالة.
